- 原迁移失败：核对事务、两表和EF历史的实际状态；不能仅换镜像就宣称数据库回滚。
- 原迁移成功但应用验收失败：先确认升级窗口内无新比较/风险或业务发布写入、原受保护业务字节未变，按已演练方式恢复旧软件；保留两张表及迁移记录，不Down删表。如果发现新业务写入或风险引用，停止自动软件回退，保留新旧镜像与数据并单独处理，避免旧软件忽略新治理证据。
