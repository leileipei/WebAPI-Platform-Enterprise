# 固定提交验收清单

所有材料须绑定同一个产品提交与实际镜像，结果必须来自本轮执行。当前清单是验收要求，不是通过记录。

- 五套完整测试：Domain／Integration／Gateway／Console／Runtime；逐项真实日志、计数、退出码、零跳过与 SHA。
- Git archive 固定提交，锁定依赖构建 Console 与七个 .NET 应用。五个实际应用容器镜像及静态文件逐 SHA 与构建一致。
- 原环境冷备后 finally 恢复；独立 UUID／端口／归属克隆恢复并验证候选→旧镜像→候选，新工作数据保持。
- 专用 Keycloak 发行方：JWT 正负、应用授权、身份隔离；不修改原控制台 SSO。
- 真实上游计数：两节点共享缓存、重试 3 次、不确定送出只 1 次、限流每入站一次、半开仅 1 次、Redis 故障旁路。
- 2.2 候选两级独立审批、双 ACK、历史回滚；运行 2.2 时拒绝旧软件。
- CUA 1440／1280：创建编辑、公钥文件、映射、六类绑定、脏草稿 Escape／焦点、Enter 不隐式保存、旧范围迟到、412、只读无保存、Review、日志／Trace。截图与实际动作、实际镜像共同绑定。
- 唯一整分支独立审查；重要问题同一修复批处理，并重新固定受影响源码、镜像与材料。
- 原文件／账号／SSO／秘密保护及原 4192 业务配置不重发。私有 JWT、sub、HMAC、凭据、转储不进入公开材料或 ZIP。

原部署升级只有最后安装验收报告可以确认。生产性能、真实企业接入、外部通知和跨环境审批不计为本批已完成。
