# 流量策略运行手册

本批在独立评审环境实现策略中心与编辑器、路由绑定、正常两级审批发布、双网关共享限流与各节点独立熔断。现有 4192 服务保持旧版本；本批未自动 Git 提交、合并或替换其镜像。

## 入口与源码身份

在本源码根目录执行 `./scripts/check-policies.sh e2e`。脚本创建随机项目、专用 PostgreSQL、Redis、两 Gateway、三源与上游；只对本次 owner 资源注入故障，结束清理本项目容器、卷和秘密。`./scripts/check-policies.sh browser` 提供独立评审入口，地址记录在 `.runtime/policy-review.json`。登录凭证仅保存在该文件指向的私有目录中，不包含于交付包。关闭评审环境使用 `node scripts/policies/cleanup-review.mjs`，它检查记录项目与每个容器 owner 后精确清理；不可按模糊名称批量删除。

构建先复制实际工作树中的构建源码，排除秘密、缓存和逃逸符号链接，产生 `docs/evidence/policies/source-manifest.json`。镜像以 sourceManifestHash 标识；baseCommit 只代表起点，不代表未提交变更已经提交。长期运行入口仍要求明确不可变 Git revision，须在源码审阅并授权固定提交后使用原部署程序升级。升级前由操作者安排维护窗口与备份，按 owner 锁、冻结依赖构建、双节点验证流程执行。出现问题使用原已验证镜像和历史自足快照回退，不用当前工作策略重建历史内容。

## 使用顺序

1. 策略中心选择项目或组织范围，新建认证、超时、限流或熔断。组织共享策略写入需要组织范围的 policy.write。
2. 动态字段校验后“保存工作配置”；服务端仍独立校验全部字段、组合与权限。保存、启停和绑定不会马上影响请求。
3. 路由页保存整组策略绑定，使用路由 Revision；同类型包含停用策略也只能一个。有效匿名认证不能绑定 ApplicationRoute 额度。
4. 策略详情选择目标环境、受影响版本并读取完整 Review。创建草稿后由两名独立审核人依次审批，再由有发布权限用户发布，等待所有冻结当前实例 ACK。
5. 草稿修订过期时先核对当前候选，再显式刷新 Review。412 保留用户输入；查看服务端最新内容后才能合并重试。

## 运行边界

限流使用 Redis TIME 原子令牌桶，环境、运行策略身份、路由、已认证应用分区；同一应用的多把 Key 共享额度。默认补充 1000/1000ms、桶容量 1500，可配置。429 携带 Retry-After。默认 Redis 故障 Reject 返回 503；Allow 继续代理并记录 Bypass，故障期间不能保证全局额度。独立决策预算默认 100ms，超时不自动重复扣令牌。Redis 重启可能重新获得 burst；这属于瞬时保护，不是持久配额或计费。

熔断默认窗口 30000ms、样本最少 20、失败比例 0.5、打开 30000ms、半开并发 1、恢复成功 3。各节点状态独立，有请求的节点可能先打开；取消、认证拒绝、限流拒绝与熔断主动拒绝不计上游失败。4xx 不能作为恢复成功。新策略修订、后端集群或实例变化重建状态；完全相同运行身份的热发布沿用状态。回滚恢复原配置字节与摘要，下发序列继续增加，不恢复过去的瞬时令牌数或熔断内存。

## 升级与排障

先升级所有启用 Gateway 到明确声明 2.1 的当前实例，再发布高级策略。缺能力节点阻止整个目标 cohort；不会静默排除节点。2.0 认证/超时快照保持可用，未知协议或非法快照不替换最后可用 generation。实例更换后旧 ACK 不能冒用当前实例身份。

排障查看工作/运行修订、desired、实例当前版本与部署序列，再关联访问日志与 Trace 决策。指标按环境统计熔断拒绝和限流存储故障；按 API、应用或后端筛选时“不适用”。不足时窗、采集断点、缺源沿用 Partial/Unavailable/Stale，空值不表示零。日志及 Trace 最多两条安全决策，不含原始 API Key、Redis Secret 或内部 bucket key。

生产性能、第三方企业系统、SSO、JWT、重试与缓存未执行/未实现，本批不增加相关承诺。

## 本机复现前提

当前验收构建使用已安装 Node 22+、pnpm、console 依赖、Docker Compose及锁定 SDK，并从本机 `webapi-enterprise-core-test_nuget-test` 卷只读复制 NuGet 缓存。其他机器须先准备锁文件依赖和该缓存；不把本机缓存前提视为可直接离线跨机器部署。交付不包含依赖缓存或私人凭证。
