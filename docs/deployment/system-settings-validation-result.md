## 实现与验收边界

| 配置 | 实际作用 | 保留边界 |
|---|---|---|
| Session TTL | 后续新登录的票据到期时间 | 既有票据到期时间不改写 |
| 密码长度/复杂度 | 后续创建本地账号 | 既有账号仍按原密码登录 |
| 新路由基础超时 | 新建省略值采用平台默认；显式值优先 | 编辑原路由必须显式保留值；仍须审批发布 |
| 审计导出开关 | 新导出请求受权限与范围交集约束 | 查询继续可用；最多10000行/8MiB |
| 两级生产审批 | 固定两级独立审批 | 单级不可用 |
| 请求体/刷新参数 | 保存部署配置意向 | 不热更新当前网关，控制面8MiB边界不改 |
| Allowed Origins、保留目标、通知 | 保存配置意向；通知仅结构测试 | 不放宽CSRF，不清理历史，不解析引用/连接/发送 |

通知测试固定说明：**结构校验通过；未解析 SecretRef，未连接 SMTP/Webhook，未发送通知。** 读取、预览、审计和CSV不回显引用原文。持久值损坏返回固定503并停止相关操作，不隐式使用零值或默认值。

CSV输出10个安全摘要列，无IP、完整before/after JSON或SecretRef。固定查询上界，逐批重验权限/范围/开关；最终在授权事务锁下准入。准入前撤权或关闭丢弃缓冲；准入后不能撤回已经发送的字节。

1. 安全策略：来源、兼容值、后续新登录/账号生效说明，布局正常。

3. 网关默认：新路由消费者与部署意向分开说明，布局正常。
4. 审计设置：允许导出和保留意向可辨，布局正常。
5. 通知：引用原文不回显，结构测试及离开保护正常。
6. 冲突：真实412保留15分钟草稿，读取最新后再预览，操作正常。
7. 确认：服务器20→草稿15的差异真实可见，焦点约束和Escape关闭正常。
8. 路由：新建默认12000，原路由30000未改，操作正常。
9. 审计导出：真实下载CSV；关闭后禁用且查询仍可用，操作正常。
10. 撤权：清空引用草稿与配置，延迟到达的旧响应不恢复数据，操作正常。
