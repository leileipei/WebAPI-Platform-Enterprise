本说明对应候选控制台的 40 页映射。页面编号、入口和现有业务架构保留；不覆盖主工作副本已有的中文文档修改。原 4180 高保真原型保留。

| 原页面 | 当前能力 | 验收边界 |
|---|---|---|
| 7、8 | JSON/YAML/URL 导入，项目来源规则、附带引用文件、固定预览和 Operation 映射 | 固定包、来源哈希和修订保护；导入不直接绕过审批发布 |
| 11 | 30 条服务端兼容性规则、证明与 Unknown、format 模式和风险评审 | 历史报告保持原证据；Unknown 不等于兼容 |

| 16、17 | API Key/JWT、超时、共享限流、熔断、重试、缓存六类策略 | 发布生成固定快照；双节点缓存身份隔离、实际重试次数与 Redis 故障按协议验证 |
