# SSO/OIDC 本批能力边界

第39页已接入真实身份源治理、分阶段连接测试、显式 SSO 用户开通与绑定、授权码登录、平台会话及撤销。名称、默认、认证配置使用不同修订语义；写操作沿用幂等与 If-Match。角色和数据范围仍由平台原流程决定。

独立本机验收使用真实 Keycloak、Postgres、双控制实例及正式 OIDC 处理器，平台 127.0.0.1 与 IdP localhost 构成真实跨站导航。验证记录与源码/镜像摘要在本批 evidence/sso 内，浏览器及设计 QA 的最终结果以 ui/qa.json 为准。

本机合成环境通过不代表企业身份服务、正式网络、生产 TLS/PKI 或生产灾备通过。生产必须配置可信 HTTPS Origin、精确回调、受控秘密文件与共享会话密钥。4192、4196、4197 本轮没有升级或重启。

没有自动开户、邮箱合并、外部 Claim 授权、UserInfo、Refresh Token、离线登录或 IdP 全局注销。本地管理员恢复入口持续保留，平台退出可能仍保留身份服务登录状态。

本批实际源码未提交；baseCommit 只表示起点，SSO 完成状态以 actual-uncommitted-build-source 清单和 SHA256 标识。升级须另次授权本地固定提交、冷备份与服务切换，顺序详见升级提案。
