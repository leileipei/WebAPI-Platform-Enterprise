# 企业工作台

入口 `/dashboard`。保留 `/` 的组织管理行为与原 4180 高保真原型，左侧工作台展开后可进入真实聚合页面。使用既有深蓝 Shell 和组织、项目、环境选择器。

## 口径

| 模块 | 范围 / 查询 | 边界 |
|---|---|---|
| API 总数 | 当前项目，目录分页返回的 total | 不以首页返回条数充当总数 |
| 请求量、成功率、P95、趋势、Top API | 当前环境，近24小时，现有指标接口 | 采集估计；覆盖不足明确说明，过期/不可用/无数据保持空值 |
| Gateway | 当前环境节点总数和前5个节点 | 包含停用身份；心跳、配置/序列一致与发布ACK分别展示 |
| 未确认告警 | 当前环境，服务端 status=Open，total与最近5条 | 不包含 Ack、Resolved 或 Silenced，不等于全部活跃告警 |
| 最近发布 | 当前环境，最近5条 | 目标配置与确认来自原发布记录 |
| 最近发布中的待审批 | 在最近50条发布中筛选 WaitingApproval，展示前5条 | 不代表全部任务，不表示当前账号可以审批；具体操作由原详情页服务端校验 |

## 权限与异常

API 计数需要项目范围 api.read；其他模块分别检查 metrics.read、gateway.read、alert.read、release.read 及环境范围。实际查询继续使用现有服务端授权，不扩大权限。

每个模块独立读取、独立返回和失败显示，15秒请求超时。手动刷新或30秒刷新重新生成24小时窗口。切换组织/项目/环境、账号或权限时立即显示新范围加载状态，取消旧请求；取消后返回的数据不得更新页面。无权限或范围失效不显示对应资源快捷链接。页面说明各模块查询时间可能略有差异，不能作为一致性事务快照。

## 验证范围

模型测试验证请求口径、权限隔离、局部HTTP错误、取消后的迟到结果与过期指标。实际 React SSR 测试验证拒绝状态、覆盖不足、离线节点与详情链接。新增导航回归保证工作台可达，同时保留根首页选中组织管理。

本轮不修改后端接口、数据库、角色权限、审批流程或网关配置；不新增个人审批资格判断或完整工作台统计服务。部署身份与当前本机状态以私有运行目录和本轮交付证据为准；本机验收不替代生产验收。
