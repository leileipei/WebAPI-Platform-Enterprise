# 版本比较流程：1440px界面QA

2026-10-06，当前应用固定来源943143f。观察对象为本机随机隔离组织/项目/环境及真实服务数据；使用内嵌浏览器操作，Chrome验证实际下载和只读权限。截图为原始浏览器1440×1024画面，JPEG无缩放转PNG后记录SHA，逐张打开查看。

六步健康检查：

1. **比较结果：通过。** 选择1.0.0→4.0.0-ui、生成服务端报告、筛选并用Enter展开片段。顶部全量Breaking=1，Compatible筛选展示0/1；筛选未掩盖风险。[截图](comparison.png)
2. **未知覆盖：通过。** 服务端真实未支持约束生成Limited，Changed=0、Unknown=2；覆盖提示与风险计数常显。[截图](unknown.png)
3. **强确认：通过。** 输入21字符说明后仍不可提交，勾选才启用；Shift-Tab在弹窗内环绕。关闭/Escape返回触发按钮；重开保留备注并重置勾选。[截图](strong-confirmation.png)
4. **评审留档：通过。** AcceptedRisk显示评审人、时间、说明、报告哈希，历史报告仍可打开。[截图](review-record.png)
5. **向导交接：通过。** reviewId由服务端解析目标4.0.0-ui，版本选择器禁用；实际创建草稿、预览并提交。更改目标有明确退出入口。[截图](wizard-handoff.png)
6. **发布摘要：通过。** 待审批发布显示可信冻结证据；申请人不能自批，两个正式审批步骤Pending。此UI申请停于WaitingApproval；双网关发布完成证据来自同镜像独立HTTP场景。[截图](release-summary.png)

其他实测：环境切换清除报告、关闭弹窗，不残留旧结果。只读账号可读报告，评审按钮禁用。JSON/CSV在筛选0行时实际下载，读回仍包含全量Breaking条目且不含私有来源字节。

布局修复：验收发现2522字符Schema片段撑大grid列；列定义改为minmax(0,1fr)，子项min-width:0。新镜像实际列宽219px、片段scrollWidth18212，内容在pre内部滚动；容器450px，页面无横向溢出。[长片段截图](long-fragment.png)。旧失败画面不作为本次来源的通过证据。

设计观察：延续深色Shell与蓝色主操作，信息按版本/计数/差异/证据分层；未知覆盖、强确认和独立审批状态直接可见。实际画面未见遮挡主按钮、失效导航或页面横向溢出。向导预览既有候选JSON保持现有功能，本批未扩大改版范围。

未验证条件：移动端、缩放与所有断点、屏幕阅读器、完整WCAG合规、容量与生产集成；晚到数据/15秒期限另有自动化回归，不能称为辅助技术或负载验收。内嵌浏览器未取得下载文件，下载通过结论仅来自Chrome。
