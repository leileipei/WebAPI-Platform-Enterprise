# 离线输出边界组件

`output_bounds.py` 只处理调用方提供的字节、本地私有普通文件和观测值。没有命令行执行器、进程启动、信号、Docker/网络访问、资源创建或终止回调；停止只是一份决策，不能代替实际停止机制或授予运行准入。

使用 Python 3.9+ 标准库。在仓库根目录验证整个诊断包：

```sh
python3 -B -m unittest discover -s tests/local_diagnostics -p 'test_*.py' -v
```

这些检查只用合成内容和独立临时文件，不运行项目SDK、应用或真实依赖。候选容量预算仍未冻结，组件没有把任何预算默认变成执行配置。

## 接口与限制

- `StopMachine(usage_limits, free_floors, started_at=..., work_seconds=..., total_seconds=..., stale_seconds=...)`：接收字节阈值和显式时间值。`observe(now, sampled_at, usage, free)` 对未知、缺项、非法/过期观测、倒退时间、达到阈值及截止锁存停止。`trip(reason)` 只接收模块白名单原因，首个原因不会被后续正常样本或次级失败替换。`finalize(evidence_complete=...)` 进入不可恢复终态。快照的 `may_advance` 仅表示未锁存停止且未终结，`grants_admission` 始终为false；无失败也只称 `observation_only`，不称验收通过。
- `LogCapture(directory, machine, soft_bytes=..., limit_bytes=..., chunk_bytes=65536)`：接收 `feed('stdout'或'stderr', raw_bytes)`，两个通道共享累计额度；每块不超过配置值且最高64KiB。软线锁存停止，但仍可在剩余额度内接收失败收尾字节；到硬接纳额度不再写入超额部分，保留已写前缀和实际观察到的遗漏计数。它不读取或停止生产者，也不提供管道排空循环。
- `finish(eof=...)`：刷新、回读摘要并核对两个文件在收尾前后的身份、大小、链接数及名称。第一次收尾结果固定，后续调用不能把未知EOF升级为完整；收尾后不能继续feed。`complete`与`durable`分开，持久化了前缀不代表输出完整。达到额度时保守记不完整；未知尾部总遗漏为null。写入、刷新或身份核对错误只给安全原因，不回显异常原文。
- `copy_trx(source_directory, source_name, destination_directory, destination_name, machine, soft_bytes=..., limit_bytes=..., chunk_bytes=65536)`：源须由生产者关闭后提供。只接收本用户拥有、无多重硬链接、无组/其他用户写权限的普通文件；拒绝链接/FIFO，打开不因FIFO等待。先检查大小，再有界复制到独占的 `destination_name.partial`；核对源的前后身份/时间/大小、目标实际内容摘要及收尾身份。失败保留不完整副本，已有文件从不覆盖/删除，成功也不自动重命名或导入结果。返回摘要针对已写入并核对的字节，不验证TRX/XML内容、用例数量或业务成功。

目录必须是调用方已经建立的绝对私有目录，属主为当前用户、模式0700，路径任何组件不能是符号链接。新输出从首次打开即0600；组件不修改传入目录或已有文件的权限。名称不能含分隔符、父目录或任意路径。目录描述符锚定文件操作；实际相同用户/0700本身不能证明目录属于新尝试，调用方仍须核对自有目录身份及允许路径。

日志字节保留原样，额度可以截在行或UTF-8字符中间，必须按不完整二进制前缀解释。组件不做脱敏；调用方必须只传允许保存的私有输出，不能传密钥、环境原文或未审查业务内容。停止原因白名单不等同于整个原始日志内容安全。

## 尚未提供的保证

- 组件只限制自身接纳的字节，不限制TRX生成者、Docker日志、目录总物理占用、稀疏文件、文件系统元数据或其他写入者。
- 文件系统调用仍可能阻塞，没有硬墙钟中断、生产者终止、排空/关闭通道适配器、资源所有权判断或清理接口。所有这些仍属于未准备的执行器边界。
- 回读、身份和时间核对检测已经观察到的变化，不提供对恶意并发写入者的原子快照或不可变证明；结果返回之后文件也仍可改变。
- 文件/目录fsync成功仅按本机文件系统返回值记录，不是所有平台、电源故障或远端存储的持久性验收；返回收据本身没有自动持久写出，调用方不得声称尚未保存的收据已经封存。
- 总配额对应、SDK401/Linux、真实登录503、最坏停止延迟与安全余量足够性均未因离线测试解除。不得用本组件绕过原内存、1000ms产品预算、T0或其他准入条件。
